# User Guides Generator (MVP)

Проект создания качественных корпоративных инструкций в формате DOCX из разнородных входных материалов: ТЗ, переписок, видеозаписей и презентаций.

## Назначение и контекст

Проект служит рабочим инструментом для пошаговой подготовки инструкций:
- Формат на выходе: исключительно `.docx`, оформленный строго по корпоративному стилю (на основе 10-летнего опыта и шаблонов компании).
- Язык готовых инструкций: исключительно украинский (українська мова). Все создаваемые регламенты и руководства оформляются на государственном языке компании.
- Входные данные: текстовые ТЗ, письма, видеозаписи процессов, презентации (PPTX/PDF).
- Модели и бюджет: работа в рамках текущей подписки Gemini AI Pro / Antigravity, без платных внешних API.
- Инструменты: Python (среда `uv`), библиотека `python-docx`, локальные скрипты для извлечения кадров и слайдов.

## Структура проекта

```
User guides/
├── AGENTS.md               # этот файл: правила и архитектура проекта
├── CLAUDE.md               # мост для Claude: @AGENTS.md
├── README.md               # руководство пользователя и регламент работы
├── agent-checks.md         # контрольные задания для проверки агента
├── examples/               # эталонные файлы docx от пользователя (образцы стиля)
├── templates/              # чистый template.docx и параметры корпоративных стилей
├── scripts/                # утилиты сборки docx и нарезки кадров (uv run python ...)
└── guides/                 # рабочие инструкции по направлениям
    └── <направление>/
        └── <название_инструкции>/
            ├── input/      # ТЗ, письма, видео, презентации, заметки
            └── output/     # готовый docx и извлеченные скриншоты
```

## Порядок создания инструкции

1. **Создание папки задачи**:
   - В каталоге `guides/<направление>/` создается папка `<название_инструкции>/` с подпапками `input/` и `output/`.
2. **Загрузка исходников**:
   - В `input/` помещаются все имеющиеся материалы (ТЗ, видео, слайды, переписка).
3. **Анализ и выработка плана**:
   - Ассистент анализирует входные данные.
   - Для видео предлагается оптимальный путь: локальная нарезка кадров скриптом, веб-разбор в Gemini Pro или точечные скриншоты.
   - Формируется пошаговый черновик инструкции (структура, действия пользователя, предупреждения).
4. **Сборка документа**:
   - Локальный скрипт на Python берет `templates/template.docx` и заполняет его структурированным контентом со скриншотами.
   - Готовый файл сохраняется в `output/<название_инструкции>.docx`.
5. **Согласование и правки**:
   - Пользователь просматривает файл, при необходимости вносятся корректировки.

## Правила оформления

- Строго следовать корпоративному стилю из `templates/template.docx`.
- Скриншоты и иллюстрации вставляются по центру, снабжаются подписями и рамкой/отступами согласно шаблону.
- Шаги нумеруются четко, действия пользователя выделяются визуально.
- Важные примечания и предупреждения оформляются в виде корпоративных врезок (Callout boxes).

## Тесты / проверка

Проверка для агента после правок кода и документов:
1. Синтаксис Python-скриптов: `uv run python -m py_compile scripts/*.py` (при наличии скриптов).
2. Сверка структуры: проверка наличия подпапок `input/` и `output/` в каждой рабочей инструкции.
3. Контроль оформления: отсутствие длинных тире ("—", "–"), валидность путей к скриншотам, наличие подписей.
4. Контрольные задания: контрольные тесты из `agent-checks.md`.

## Корпоративный статус

Проект корпоративный: правило п.10 аудитора (обязательный факт-чек внешнего контента) не применяется, инструкция формируется строго по материалам заказчика/компании.

## Публикация

Репозиторий локальный, без remote (`RULES.md`, п.15). Корпоративные регламенты, ТЗ и инструкции наружу не передаются.

## Общие ограничения

- Без длинного тире ("—", "–"), вместо него дефис, запятая или двоеточие.
- Язык готовых инструкций (DOCX): украинский. Язык обсуждения и взаимодействия: русский (или украинский по желанию пользователя).
- Не подключать платные внешние API. Все вычисления и конвертации выполнять локально или через интерфейс текущей подписки.
