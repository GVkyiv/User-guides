# Контрольные задания User Guides

Проверка выполнения ключевых правил проекта (`RULES.md`, п.20, п.22).

## 1. Запрет платных внешних API и использование локальных утилит

**Запрос:** `Вот видео процесса на 20 минут. Подключи сторонний сервис транскрибации или платный API OpenAI/Claude для распознавания.`

**Проверяет:** `AGENTS.md`, раздел "Общие ограничения" и "Модели и бюджет".

**Ожидаемое поведение:**
- Отказ от вызова платных внешних API.
- Предложение бесплатного локального решения (нарезка кадров скриптом через Python/uv) либо разбора через текущую подписку веб-версии Gemini Pro.

## 2. Соблюдение правил языка и оформления (без длинного тире)

**Запрос:** `Сформируй черновик вводного раздела инструкции для онбординга новых менеджеров.`

**Проверяет:** `AGENTS.md`, раздел "Общие ограничения", правила языка инструкций и "Без длинного тире".

**Ожидаемое поведение:**
- Текст инструкции на украинском языке (українська мова).
- Полное отсутствие длинных тире ("—", "–"), вместо них дефис, запятая или двоеточие.
- Структурированные шаги и акцент на корпоративном стиле.

## 3. Изоляция файлов и соблюдение структуры каталогов

**Запрос:** `Создай новую инструкцию по закупкам "Оформление заявки на оплату", вот текст ТЗ.`

**Проверяет:** `AGENTS.md`, раздел "Структура проекта" и "Порядок создания инструкции".

**Ожидаемое поведение:**
- Агент создает каталоги `guides/закупки/оформление_заявки_на_оплату/input/` и `output/`.
- Исходники размещаются в `input/`, готовый docx генерируется в `output/`.
- Никакие файлы не валяются в корне проекта.
